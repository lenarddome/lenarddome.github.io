**psp-torch** is released! :rocket: Parameter space partitioning, now in PyTorch and running on the GPU. It also includes a tools for g-distance and adjacent analyses (Dome & Wills, 2025). Install with `pip install psp-torch`, and see the [documentation](https://lenarddome.com/psp-torch/).
